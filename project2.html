Below are links to two subpages that demonstrate simple JavaScript functions and input validation:

  • Part 1: Grade calculator. The script reads four scores from a form (homework average, midterm, final exam, and participation), validates that each value is between 0 and 100, then calculates a weighted final average and rounds it. Next, it converts the numeric score to a letter grade (A–F), displays the result, and adds a message if the student must retake the course. Reset clears the output.
  • Part 2: Sales and earnings calculator. The script reads quantities for four items, validates that each input is a whole number greater than or equal to 0, then multiplies the quantities by fixed item prices to get totals. It sums total sales and calculates weekly earnings as a $250 base salary plus a 9% commission. The results are written into output fields, and reset clears all fields and errors.
