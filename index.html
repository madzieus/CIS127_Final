Why JavaScript?

Modern front-end development benefits a lot from JavaScript, which continues to grow and evolve. Developers also have access to a huge ecosystem of frameworks and tools.

For now, I’m taking my first steps in the front-end world from the perspective of someone actively sharpening their skills. In this project, I’m using vanilla JavaScript to practice and strengthen those skills.

For a future web developer, JavaScript means:

  1. A much broader range of options for building abstractions and reusable logic.
  2. In many cases, faster development time — and better overall efficiency.
  3. A strong foundation for learning modern frameworks that are standard in web development, such as React and Next.js.
  4. For people coming from HTML/CSS only, JavaScript is a great first programming language with huge possibilities.
  5. A gateway into front-end development and a solid stepping stone toward back-end work, since JavaScript also powers many server-side solutions today.
