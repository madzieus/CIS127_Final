Below are links to two subpages that demonstrate simple JavaScript use cases:

  • Subpage 1: JavaScript changes the text color and font. This script selects the page element with the id output, builds a small block of HTML as a template string, and then inserts it into that element using innerHTML. The inserted content displays “xy” in bold red Times New Roman, “12” in blue Arial, and “89” in green Impact italics.
  • Subpage 2: JavaScript performs basic arithmetic operations on integers. This script grabs references to the button, three input fields, and a results text area. When the user clicks Process Data, it reads the three input values, trims whitespace, and validates that each one is a real number using the isNumber() function. If any value is invalid, it displays an error message in the results area and stops. Otherwise, it converts the inputs to numbers, calculates the sum, average, product, as well as the smallest and largest values, formats these results into a multi-line string, and outputs it in the results text area.
